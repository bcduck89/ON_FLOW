# ON_FLOW Transaction Engine

## 목적

은행에서 다운로드한 거래내역 Excel 파일을 업로드하면, ON_FLOW는 기존 거래와 중복되는 항목을 자동으로 제외하고 신규 거래만 데이터베이스에 누적 저장한다.

이후 입금 거래 중 회비 금액에 해당하는 거래를 회원과 자동 매칭하여 회비 납부 기록을 생성하고, 회원의 회비 유효기간을 갱신한다.

## 입력 파일

초기 지원 형식:

- 카카오뱅크 Excel 파일
- 확장자: `.xlsx`

## 거래 누적 원칙

거래내역은 append-only 방식으로 관리한다.

- 기존 거래는 삭제하지 않는다.
- 기존 거래는 원칙적으로 수정하지 않는다.
- 같은 거래가 다시 업로드되면 중복 거래로 판단하고 저장하지 않는다.
- 신규 거래만 `transactions` 테이블에 추가한다.
